# Сайт фотографа vaag.ph

Учебный проект. Практическая работа 10 (3D-анимация) и практическая работа 4 (оптимизация веб-приложений).

## Состав

| Файл | Что внутри |
|---|---|
| `index.html` | разметка всех разделов |
| `style.css` | стили, блоки разделены комментариями с номерами заданий |
| `script.js` | слайдер портфолио, форма карты, оплата CloudPayments |

**Практическая 10 — 3D-анимация**

1. Изометрическая витрина отпечатков — раздел «Витрина отпечатков»

3. Перелистывание карточек вокруг оси X — раздел «Что снимаю»

5. Ссылка на сайт и адаптивность — см. ниже

## Что нужно подставить своё

**CloudPayments.** В `script.js` найдите переменную `PUBLIC_ID`. Сейчас там тестовый ключ — деньги не списываются, но окно оплаты открывается и работает. Свой ключ берётся в личном кабинете CloudPayments: раздел «Сайты» → ваш сайт → Public ID. Тестовые карты для проверки есть в документации CloudPayments.

**Почта для заявок.** В `index.html` в форме обратной связи замените:

```html
action="https://formsubmit.co/ВАША_ПОЧТА@example.com"
```

на свой адрес. После первой отправки FormSubmit пришлёт письмо со ссылкой подтверждения — пока не нажать, заявки приходить не будут. Там же в поле `_next` укажите адрес своей страницы на GitHub Pages, чтобы после отправки человека возвращало на сайт.

## Задание 3. Регистрация на GitHub

1. Откройте github.com и нажмите Sign up.
2. Укажите почту, придумайте пароль и имя пользователя — оно попадёт в адрес сайта, поэтому лучше латиницей и без лишних символов.
3. Подтвердите почту по ссылке из письма.

## Задание 4. Публикация исходного кода

Через сайт, без установки Git:

1. New repository → имя, например `vaag-ph`. Тип **Public** — на бесплатном тарифе Pages работает только с публичными репозиториями.
2. Внутри репозитория: Add file → Upload files. Перетащите `index.html`, `style.css`, `script.js`, `README.md`. Файл главной страницы обязательно должен называться `index.html`.
3. Commit changes.

Через Git в консоли:

```bash
git init
git add .
git commit -m "Практические работы 4 и 10"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/vaag-ph.git
git push -u origin main
```

Включение хостинга: Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save. Через минуту-две вверху страницы появится адрес.

## Задание 5. Ссылка и адаптивность

Адрес сайта: `https://ВАШ-ЛОГИН.github.io/vaag-ph/`

Ссылка на сам репозиторий (её обычно и просят сдать): зелёная кнопка **Code** → вкладка HTTPS → адрес вида `https://github.com/ВАШ-ЛОГИН/vaag-ph.git`. Либо просто адрес страницы репозитория из адресной строки.

Что в проекте отвечает за адаптивность:

- `<meta name="viewport" content="width=device-width, initial-scale=1">` — без него мобильный браузер отрисует страницу как десктопную и уменьшит её.
- `clamp()` в размерах заголовков — шрифт плавно меняется вместе с шириной экрана, без ступенек на брейкпоинтах.
- `grid-template-columns: repeat(auto-fit, minmax(...))` в блоках услуг и выбора съёмки — количество колонок пересчитывается само.
- Медиазапросы `900px`, `760px`, `640px`: изометрическая витрина перестраивается с трёх колонок на две и одну, слайдер портфолио разворачивается из горизонтального в вертикальный, форма оплаты становится в одну колонку, меню в шапке превращается в горизонтальную прокручиваемую ленту.
- CSS-переменные `--plate`, `--thick`, `--ph` — на узких экранах меняется одно значение, а вся 3D-геометрия пересчитывается от него.
- `@media (prefers-reduced-motion: reduce)` — анимации отключаются, если человек попросил об этом в настройках системы.

Проверить: F12 → значок телефона (Toggle device toolbar) → пройтись по iPhone SE, iPad и произвольной ширине.

## Про скорость загрузки

Фотографии подключены по ссылкам с `i.wfolio.ru`. У всех тегов `<img>` стоит `loading="lazy"` и `decoding="async"` — кадры из нижних разделов не грузятся, пока до них не долистают. Для сдачи надёжнее скачать фото в папку `img/`, сжать до ~1200 px по длинной стороне и поменять `src` — тогда сайт откроется даже без интернета и будет заметно легче.
